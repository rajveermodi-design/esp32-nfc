# Scope and Ethics Statement

## Project Scope
This project investigates 13.56 MHz RFID/NFC security architecture using an ESP32 microcontroller, contrasting unauthenticated UID identification against authenticated cryptographic sector access.

## Ethical Boundaries & Constraints
- All experimental testing is strictly restricted to lab-owned, blank, or self-provisioned RFID/NFC cards and tags.
- No testing, cloning, replay, or capture attempts will be conducted against campus turnstiles, hostel entry gates, or any live institutional access-control systems.
- The project is framed strictly as an academic vulnerability analysis.
